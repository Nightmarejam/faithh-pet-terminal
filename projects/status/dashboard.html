    Power BI data sources

    These CSV files update when you run python3 scripts/export_status_csv.py or scripts/refresh_dashboard_data.sh:

    • projects/status/tracks.csv — one row per track, use for status overview
    • projects/status/gates.csv — one row per gate, use for progress bars
    • projects/status/components.csv — one row per component, use for change history

    In Power BI: Home → Get data → Text/CSV → navigate to each file → Load. Build relationships: tracks[track_id] → gates[track_id].

### Parallel execution model (how futures run + collected)

#### Production path in `faithh_professional_backend_fixed.py`

- **Executor**: `CHIP_EXECUTOR = ThreadPoolExecutor(max_workers=5, thread_name_prefix="chip_")`
- **Submission model**: one future per chip call; chips include file I/O chips plus the slower network RAG chip.
- **Collection model**: `for future in as_completed(futures, timeout=10.0)` gathers results as they finish.
- **Timeout handling**: if the 10s timeout fires, it proceeds with partial results; remaining futures are cancelled and recorded as `None`.
- **Ordering**: results are *processed* in a deterministic `priority_order` to keep output stable.

#### Separate engine in `backend/parallel_chip_engine.py`

- **Executor**: `ParallelChipEngine(max_workers=5)` uses `ThreadPoolExecutor(max_workers=max_workers)`.
- **Collection model**: `for future in as_completed(futures, timeout=5.0)` with per-future exception capture into `ChipResult.error`.

### What each chip does (one sentence each)

Based on `faithh_professional_backend_fixed.py` chip functions:

- **`conversation_history`**: pulls recent session chat history from the backend’s session store for continuity.
- **`self_awareness`**: injects FAITHH identity/purpose constraints to prevent “generic assistant drift.”
- **`constella`**: injects Constella framework context (governance concepts and definitions) when the query is Constella/governance-related.
- **`decisions`**: injects recent/important decisions and their rationales from the decision log to answer “why did we…” queries.
- **`project_state`**: injects current multi-project status from `project_states.json` to ground project questions.
- **`scaffolding`**: injects open loops/parked tangents/last focus from `scaffolding_state.json` for orientation and resumption.
- **`project_structure`**: injects a snapshot of repo/project structure to support implementation tasks and navigation.
- **`rag_search`**: queries ChromaDB (`faithh_knowledge_base`) for semantically relevant chunks and returns a formatted context block plus raw docs.

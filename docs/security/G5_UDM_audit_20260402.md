# UDM Dream Machine v1 Audit

## Access
- [ ] UniFi controller accessible at https://192.168.1.1 (or your UDM IP)
- [ ] Logged in with admin account
- [ ] Admin account has MFA enabled (UniFi > Settings > Admins)

## Firmware
- [ ] Firmware version: ___________
- [ ] Firmware is latest (check: unifi.ui.com for current version)

## WAN / Port Forwards (Settings > Routing > Port Forwarding)
- [ ] List all port forward rules below and confirm each is intentional:
  - Rule 1: ___________
  - Rule 2: ___________
  - Rule 3: ___________

## LAN / Network segmentation (Settings > Networks)
- [ ] List all defined networks/VLANs:
  - Default LAN: ___________
  - IoT (if any): ___________
  - Guest (if any): ___________
- [ ] Gen8 (`servicebox`) is on main LAN: ___________
- [ ] NAS is on main LAN: ___________
- [ ] IoT devices (if any) are isolated to IoT VLAN: ___________

## Firewall (Settings > Security > Firewall)
- [ ] List any custom WAN-in rules
- [ ] List any LAN-in rules that allow inter-VLAN
- [ ] Confirm no "allow all" rules exist

## SSH on UDM (optional but useful for audit)
- [ ] Enable via UniFi > Settings > System > Device SSH Authentication
- [ ] SSH in and run: `ip a`, `ss -tulpen`, `iptables -L -n`

## Recommended immediate UDM actions
1. Disable any port forward rules not explicitly required.
2. Enable UniFi MFA for admin account if not done.
3. Update firmware to latest stable.
4. If IoT devices present, create IoT VLAN and move them off main LAN.
5. Enable IDS/IPS (Threat Management) if supported.

# Audio Workflow Reference

## MacBook Pro M1 Setup
- Primary use: Mobile mastering, remote collaboration
- DAW: Luna (for remote with SD partner)
- Mastering: WaveLab when needed
- Monitoring: Headphones with Sonarworks correction

## Remote Collaboration (South Dakota Partner)
- Partner's setup: M2 Mac Mini with Luna DAW
- Connection: JackTrip or SonoBus for pristine audio
- Workflow: They track, you master

## Quick Commands

### Audio Routing
See ~/Audio-Scripts/ for:
- mastering-mode.sh
- mixing-mode.sh
- setup-jacktrip-routing.sh

### Common Tasks
- Start mastering session: Load WaveLab template
- Remote collab: Check SonoBus connection first
- Monitoring: Use calibrated headphones

## Session Checklist
1. Close unnecessary apps (save CPU for audio)
2. Check audio interface connection
3. Set correct sample rate (match project)
4. Test monitoring before starting work
